↑If a malicious person changes code to expose the secret token, the sensor is invalidated forever. The person may use the token elsewhere, but the IP discrepancy will show that it isn't our token. Some details need to be fleshed out.
Private key: locks the code

Only firmware we signed runs on a sensor. Someone holding a sensor can't load their own code.

Token: proves it's real

Each sensor sends its own secret on connect. No valid token, no connection.

TLS: encrypts traffic

Token and events travel encrypted, so nobody on the network can read, steal, or change them.

Server decides

The browser is never trusted. Every request is checked on the server.

Own data only

Every Host query is filtered by account. No Host reaches another's data.

Shared only

Guests reach only a few public, read-only endpoints that return shared items. Everything else needs a Host session.

Database not public

Only the server reaches it. Secrets in env variables. Tokens and claim codes stored as hashes.
