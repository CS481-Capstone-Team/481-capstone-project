Security Basics

Sensorsecure boot
🔒 TLS
+ sensor token⟶
Serverchecks token
1 · Digital signature

We sign each firmware build with our private key, kept off the sensor. Any change to the code breaks the signature.

2 · Public key

Burned into the Pico 2 W once, can't be changed. It can check signatures but can't make them.

3 · Secure boot

On every power-up the chip checks the firmware's signature with the public key. Bad signature: it won't run.

4 · TLS + token

Encrypts sensor to server traffic. Each sensor sends its own secret token, so fake sensors are refused.
